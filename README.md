# Library Management System

## Aim
To identify and manage the requirements of a Library Management System using GitHub.

## Project Description
This system manages library activities and reduces manual work.

## Modules

### 1. Book Registration
- Add new books.
- Enter Book ID, Title, Author and Quantity.

### 2. Book Searching
- Search books by ID.
- Search books by Title or Author.

### 3. Book Issuing
- Check book availability.
- Issue books to students.
- Record issue date and due date.

### 4. Book Returning
- Accept returned books.
- Update book availability.
- Record return date.

### 5. Fine Calculation
- Calculate delayed days.
- Calculate fine amount for late returns.

## Tools Used
- GitHub
- GitHub Issues
- GitHub Projects

## Conclusion
The requirements of the Library Management System
were successfully identified and organized using GitHub.
